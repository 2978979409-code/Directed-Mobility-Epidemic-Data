# Sources, attribution, and license boundaries

This repository contains a mixture of author-generated outputs and frozen
third-party data. Inclusion in one repository does not replace the original
source's terms.

## Kaggle integrated mobility and health data

- Dataset: **US COVID-19 & Human Mobility (2021)**
- Creator recorded in the supplied metadata: Amro Askar
- Source: https://www.kaggle.com/datasets/amroaskar/us-covid-19-and-human-mobility-2021
- Supplied metadata license: **CC0: Public Domain**
- Frozen metadata: empirical_data/raw/kaggle_human_mobility_2021_metadata.json
- Frozen archive: empirical_data/raw/kaggle_human_mobility_2021.zip
- Extracted table: empirical_data/raw/kaggle_human_mobility_2021/IntegratedData.csv

The metadata acknowledges health data from the New York Times and Johns Hopkins
University via disease.sh, and mobility data from Google COVID-19 Community
Mobility Reports. Users should retain those attributions.

## New York Times state COVID-19 archive

- Source repository: https://github.com/nytimes/covid-19-data
- Frozen file: empirical_data/raw/nytimes_us_states_official.csv

The source repository publishes its own license and attribution conditions.
Those source terms govern this snapshot.
